# Task Management API 📝

A clean and lightweight RESTful API built with **Node.js** and **Express.js** for managing tasks. Built as part of the FlyRank Internship assignment.

---

## 🚀 Features

* **Full CRUD Operations**: Create, Read, Update, and Delete tasks.
* **Interactive Documentation**: Integrated **Swagger UI** for testing endpoints directly from the browser.
* **Validation & Error Handling**: Proper HTTP status codes (`200 OK`, `201 Created`, `204 No Content`, `400 Bad Request`, `404 Not Found`).
* **Health Check**: Endpoint to verify if the server is running (`/health`).

---

## 🛠️ Tech Stack

* **Runtime**: Node.js
* **Framework**: Express.js
* **Documentation**: Swagger UI (`swagger-ui-express`)

---
